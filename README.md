# DPN Directory Services

> An open-source, Linux-first domain operations console for Samba Active Directory.

**Status:** Initial development. This project is not yet a production identity provider or a replacement for the Samba AD DC engine.

DPN DS will provide centralized observability and, in subsequent reviewed releases, controlled administration of users, groups, devices, domain controllers, and Linux login policy. Samba AD DC remains the authoritative directory, Kerberos and DNS implementation. The management console will never implement its own password storage, Kerberos protocol, or LDAP server.

Development will take place through pull requests with automated quality and security checks. Installation and deployment details will be introduced with the first implementation PR.
